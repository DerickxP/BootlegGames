BootlegGames

Sobre o Projeto

🇧🇷

BootlegGames é uma plataforma de venda de jogos online desenvolvida como projeto final da disciplina de Web Coding. O objetivo principal foi construir um sistema funcional que reproduzisse os principais recursos de uma loja digital moderna, incluindo autenticação, gerenciamento de usuários, catálogo de jogos, fluxo de compras e um painel administrativo, tudo integrado a um banco de dados relacional.

Apesar do nome descontraído, BootlegGames foi desenvolvido com foco em arquitetura limpa, organização de código e boas práticas de desenvolvimento web. O projeto continuará sendo aperfeiçoado e estará presente no GitHub e LinkedIn como parte do meu portfólio profissional, demonstrando minhas habilidades no desenvolvimento de aplicações web completas e escaláveis, além do meu compromisso com aprendizado contínuo e evolução técnica.

🇺🇸

BootlegGames is an online game marketplace developed as the final project for the Web Coding course. The main goal was to build a fully functional system that replicates essential features of a modern digital storefront, including authentication, user management, a game catalog, purchase flow, and an administrative panel — all integrated with a relational database.

Despite its playful name, BootlegGames was developed with a strong focus on clean architecture, code organization, and solid web development practices. The project will continue to evolve and will be featured on GitHub and LinkedIn as part of my professional portfolio, showcasing my ability to build complete and scalable web applications, as well as my commitment to continuous learning and technical growth.
